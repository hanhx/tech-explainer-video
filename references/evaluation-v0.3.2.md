# 0.3.2 验证记录

这次改动来自 Transformer 讲解的多轮反馈。开头要让观众知道整期能解释什么。翻译历史、逐步生成和推理能力分别定位。跟拍“会”的 Q 前，先交代为什么当前输出要从这个位置读。术语旁白和画面保持分别查。封面用主题和全片收获定主次。

Transformer V11 的现有时间轴为 321.7 秒，23 个 cue，79 个音效事件。本轮读取了时间轴和已有的技术校验报告，复用其制作经验，另用新主题检验叙事和动画。本轮的评测对象是 Skill 与短样片。

## 新样例

[刷新网页，为什么有时不用重下？](../assets/examples/etag-revalidate-v1/storyboard.md) 是 27 秒可复现像素动画。两端持有的页面全程可追踪，两次请求都带旧标签。变化的只有服务器持有的页面与回传结果。一条下方回程先传小回执，再传带正文的响应。标签和短字幕给机制命名。机制范围和原始标准见分镜。

| 检查 | 实际结果 |
|---|---|
| Skill 结构 | `quick_validate.py` 通过 |
| 旧案例复现 | Wi-Fi 样例的 4 张 golden 帧一致，个人音频在分发基线缺席 |
| 去文字与接触表 | 生成正常草稿、静音无字片和 4 行接触表。第 1 行是触发与发出，第 2 行是比对，第 3 行是沿用，第 4 行是接收并替换。四行保持同一机位，关注点跟着实际动作走 |
| 零上下文复述 | 无字版能复述两种结果，前三镜“半懂”，末镜“懂”。无字条件下，标签身份、具体比较字段和小回执含义仍需猜。首次复述后移动了新正文的返程轨迹，复核读到新正文和响应一起返回，旧页面留到落点。复核沿用同一审查者，关卡通过 |
| 最终媒体 | 1280×720，30 fps，810 帧，H.264/AAC 完整解码。核查 9 帧的左右页面状态和 11 个音效窗口，额外导出 390 像素宽的手机尺寸抽帧 |

新样片有字幕和动作音效。无配音和配乐，人工完整试听、手机实机观看及真实观众理解仍待验证。本轮样片覆盖了 E75–E76 的局部叙事与动画行为。Transformer 全片再剪、真实配音节奏以及 E77 的成套封面和发布效果均未纳入本次验证。
