# 视觉调研与素材准备

配合主流程的「前期视觉调研与素材准备」使用。关键镜头缺少表达参考时读第一节，粗分镜有素材缺口时读第二节。已有明确的频道规范、风格和素材时直接沿用。

## 先找这个镜头需要的表达方法

1. 用一句话写清镜头问题，例如「怎样让观众看出两个文件先共享数据，改动后只有其中一个指向新数据？」优先解决关键动作、对象连续性或画面焦点。
2. 从本期项目已有参考、用户提供的参考或可访问的外部作品中找处理过类似画面问题的片段。用焦点是否清楚、对象能否持续追踪、前后状态是否易辨、手法能否迁移筛选所有候选。候选都弱时，继续找或直接做小样试画。按对象和动作组合搜索词，例如 `shared object split animation`。构图和造型可查作品集，连续动作和节奏优先看完整片段。可从 Vimeo、Behance、YouTube 或 Motionographer 找线索。
3. 记录作品链接或本地位置、时间码、实际观察、借用的做法和本期落点。静帧支持判断构图、用色、文字和对象造型。评价动作和节奏时，以实际观看的片段为依据。参考作品借用表达方法，画面与素材的使用按各自许可办理。详细拆解按 [参考风格的迁移与验收](reference-style-review.md)。
4. 把做法写进关键镜头的「初态 → 动作 → 结果」。需要探索新风格时，按 [画面风格](visual-styles.md) 围绕同一关键镜头比较方向，说明各自擅长交代什么以及推荐理由。本轮包含制作时，把涉及对象分离、替换或去向的关键动作带入动态预演。

参考链接、时间码和设计决策记入分镜开头或视觉笔记，也可放进项目的 `references/`。参考画面要进入正片时，按制作素材重新核对许可并登记。下面是参考笔记示例。

| 参考位置 | 观察与可借用的做法 | 本期镜头 |
| --- | --- | --- |
| 能对照共享对象的片段，附链接和时间码 | 保持对象标记和机位，让观众持续追踪同一个对象 | 两个文件先指向同一组块。修改时保持原块可见，只移动副本被改那一块的指向 |

## 粗分镜后，按缺口准备素材

- 优先处理会影响画面理解的缺口，记录所需对象、使用镜头、观众要看见的变化和素材取得方式。按镜头选择现有素材、原创绘制或生成、真实录屏、外部素材。技术机制画面应保留可控制的状态变化。
- 现有素材只在本期项目内查找，能自制或录制的直接按镜头需求准备。需要外部素材时，按实际缺口搜索具体条目。候选记录原始条目链接、可查看的预览、使用镜头和适用规格，如分辨率、格式、透明背景或有效时长。音效按动作试听，见 [外部音效](motion-and-sound.md#可商用的外部音效)。
- 采用前核对实际条目和许可原文，分别核对成片发布与源文件分发，记录商用与平台范围、编辑限制和署名要求。许可不明时用已有授权或自制替代。用户要选的方向、付费素材或需要用户取舍的授权事项，先展示候选再确认。
- 把已选且可用的素材下载或拷贝到 `$PROJECT/assets/` 或项目内已有素材目录，保留可辨识的文件名和扩展名。沿用已有素材表，缺省使用 `$PROJECT/asset-manifest.md`，记录素材名、作者、条目链接、许可及链接、获取日期、使用镜头、项目相对路径和所需署名。仅允许随成片发布的素材在共享源工程里保留获取说明。
- 前期交接时明确哪些条目已归档、哪些待确认、哪些仍缺，给已归档条目的本地路径。有缺口时说明受影响的镜头。只做前期策划时，按主流程交付策划和已准备的素材。
