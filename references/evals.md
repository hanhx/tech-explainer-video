Runner 应记录实际 Agent/脚本、Python/Manim 和相关工具版本。Grader 区分确定性脚本检查、人工看帧、动态观看、听音及独立 Agent 评判。没有授权和隔离条件时不自行启动其他 Agent。

E04 的 starter 小样是已知示例的执行检查，不是盲测或未见题目的泛化证明。E06 的历史修复记录可以用于设计 Skill，但不能作为新 Skill 已成功执行该用例的证据。

E12/E13 的既有“地址”“逐层”修复与反馈是规则来源，可回查实际素材、正文和哈希；这样的历史回放不是新版本 Skill 的独立行为评测。未重新生成并完成实际听音时，不声明新的发音质量测试通过。

新版本需按改动选择相关用例；独立评测或未见主题完整成片没有运行就标记未运行。quick_validate.py 只验证 Skill 结构；不自动运行本表，也不证明视频专业程度、声音一致或观众理解效果。
