# Agent 渐进式披露 · 样片（tech-explainer-video 0.3.0 试做）

## 导演阐述

- **观众**：用过 ChatGPT/Claude、听说过 Agent 和 Skill 的开发者；知道“上下文窗口有限”，不清楚 Skill 怎样被加载。
- **看完能解释**：为什么装了很多技能，Agent 也不会被撑爆——三层按需加载：简介 → 正文 → 文件/脚本。
- **要打掉的误解**：“装的技能越多，每次请求就越慢越贵”。
- **高潮镜头**：同样 100 本说明书，一边把窗口撑爆变红，一边只在底部占一小条（第 6 镜，规模反差）。
- **对标**：Kurzgesagt 的扁平造型与深色底高饱和配色 + ByteByteGo 的“东西在框之间流动”。借用：①几乎不放说明文字，只留对象标签；②每 2–3 秒一次可见变化；③统一圆角、2 种语义色（橙=技能，青=用户问题，红=超限）。
- **引擎**：本机无 Manim；画面以方块、卡片、流动和变形为主，用 Python 逐帧（Pillow）+ ffmpeg 绘制。
- **核实**：Anthropic Agent Skills 文档——启动时只把每个 Skill 的 name/description 放入系统提示；判断相关后再读 SKILL.md 正文；正文引用的其他文件按需读取，脚本通过执行调用，代码本身不进入上下文，只有输出进入。片中占比数字为**示意**，不是实测。
